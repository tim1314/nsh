根 `Cargo.toml` 通过 `[workspace]` 将 `crates/*`（nsh-core、nsh-engine、nsh-platform-*、nsh-js、nsh-bundler、nsh-cli、nsh-dev 等）与若干 examples/native 子项目纳入同一工作区，默认成员为 `crates/xtask`，并通过 `exclude = ["crates/gpui"]` 把 GPUI 后端作为独立子工作区隔离；所有 crate 共享 `[workspace.dependencies]` 中锁定的 nsh-* 内部包版本与第三方依赖，确保跨 crate 的 ABI 一致。

- Rust 工具链由 `rust-toolchain.toml` 锁定为 stable，并预注册 Apple iOS/macOS、Android 等多目标，配合 `.cargo/config.toml` 完成交叉编译。
- 发布流程由 `crates/xtask` 驱动（`cargo run` 默认运行），负责打包、签名、分发；`.github/workflows/` 中的 CI 复用同一工作区触发多平台构建。
- 顶层 `docs/`、`website/`（Astro 站点）、`examples/`（示例应用集合）与 `skills/`（AI 编码技能规范）不属于 Rust 工作区，而是围绕同一 NSH 框架的配套产物：docs 提供架构说明，website 对外展示 API 与 Playground，examples 演示各后端用法，skills 约束开发实践。
- 构建优化集中在根 `Cargo.toml`：release 启用 fat LTO、单 codegen-unit；web profile 针对 `nsh.wasm` 体积做 `opt-level=z`；对 quickjs-jit、taffy、syntect、tiny-skia、resvg 等热点 crate 在 dev 下单独提升 opt-level，保证编辑器/渲染性能。
