站点以 Astro 7 + Tailwind v4 为渲染层，`astro.config.mjs` 通过 `unified` 管线挂载自定义 remark/rehype 插件链（`remarkStripTitle` → `remarkLocaleHeadingIds` → `remarkCallouts` → `remarkCodeTabs` → `remarkDocLinks` → `remarkDemo`），并接入 Shiki 代码高亮与 Pagefind 站内搜索。

内容组织采用 Astro Content Collections：`src/content.config.ts` 将 `docs/`、`elements/`、`modules/` 及其 `zh-CN/` 镜像分别注册为 collection，schema 统一约束 title/description/order/group/demo 字段；页面路由由 `src/pages/[locale]/[section]/[...slug].astro` 等动态路由驱动，支持 `/docs/*`、`/zh-CN/docs/*` 以及 `/apps/*`、`/playground` 等平台页。

演示系统围绕 `website/demos/*.tsx`：每个 demo 是独立的 nsh 应用，在文档中通过 frontmatter `demo:` 引用；`src/lib/demo.js` 在构建时读取源码并用 Shiki 高亮，同时根据 `public/play/index.html`（由 Rust `cargo xtask web` 生成）是否存在决定渲染 live iframe 还是仅源码面板。

构建脚本 `scripts/play.js` 在 dev/build 前自动执行 `bun install` 和 `cargo xtask web`，若缺少 wasm32 target 则降级为“仅源码”模式；`scripts/versions.js` 配合环境变量 `SITE_OUT_DIR` 输出多版本站点。

主题与样式集中在 `src/light.theme.json` / `src/dark.theme.json`（Shiki 主题）与 `src/styles/global.css` / `ui.css`，并通过 `@tailwindcss/vite` 注入 Vite 管线。
