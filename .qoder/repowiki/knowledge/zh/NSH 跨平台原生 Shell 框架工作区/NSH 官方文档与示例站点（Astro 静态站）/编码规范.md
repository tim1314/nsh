- 文档与 API 参考按 section 分目录（docs/、elements/、modules/），中英文镜像放在 zh-CN/ 下同名结构，由 content.config.ts 统一注册。
- Markdown 页面通过 frontmatter 声明 title/description/order/group/demo，用于侧边栏排序、分组与嵌入对应 demos/*.tsx 示例。
- 自定义 Markdown 扩展以 remark/rehype 插件形式实现（callouts、code-tabs、doc-links、demo 嵌入、heading anchors），并在 astro.config.mjs 的 unified 管线中集中注册。
- Demos 以 `el-<component>.tsx` 命名于 website/demos/，文件名即逻辑名，通过 frontmatter `demo:` 字段引用，无需路径前缀。
- 运行时 UI 文案集中在 `src/lib/demo.js` 的 COPY 对象中按 en / zh-CN 键区分，模板字符串通过 t.xxx 取值而非硬编码。
- 构建期产物（如 Shiki 主题、Playground 入口）通过相对 process.cwd() 的路径读取，使 Astro 在仓库根目录下运行。
