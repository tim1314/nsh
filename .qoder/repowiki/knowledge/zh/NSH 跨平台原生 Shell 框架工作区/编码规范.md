- 所有内部 crate 通过 `[workspace.dependencies]` 引用 `nsh-*` 包，版本号与工作区 `version = "0.6.0"` 保持一致，避免版本漂移。
- 平台相关 crate（nsh-platform-linux/apple/macos/windows/android/ios/tui）一律关闭 default features，仅按需启用功能面。
- 公共 crate 暴露的 pub 接口遵循 `missing_docs=warn`、`unreachable_pub=deny`、`private_interfaces=deny` 的 lint 规则。
- Apple 绑定统一使用 `objc2-*` 并以显式 feature 列表裁剪，不引入未使用的 framework 以降低链接与启动开销。
