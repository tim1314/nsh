本模块由两个并列的 SKILL 目录构成，每个目录遵循统一的 `SKILL.md` + `references/` 子目录结构：
- `skills/nsh/SKILL.md` 是主入口，按 Rust / Rust+TSX / TSX 三种模式组织，通过表格引导选择模板 (`nsh init --template rust|mixed|ts`)、命令循环 (`nsh check/build/test/run`) 与参考页面（`references/rust.md`、`tsx.md`、`mixed.md`、`rust-ui.md`、`rust-testing.md`、`rust-recipe.md`、`tsx-recipe.md`、`coding-guides.md`、`tooling.md`）。
- `skills/nsh-design-guides/SKILL.md` 是独立的设计规范入口，指向 `references/design-guides.md`，在 UI 相关任务前被 `nsh` 技能引用。
- 依赖方向单向：`nsh` 技能引用 `nsh-design-guides` 的设计规则；两者都只读外部文档（`https://nsh.dev/docs/*`、`https://github.com/longbridge/nsh`），不引入运行时代码。
- 文件解析采用 YAML front matter（`name`、`description`）作为技能元数据，正文以 Markdown 表格和章节导航驱动 AI 工作流。
