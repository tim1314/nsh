examples/ 是扁平的示例目录集合，每个子目录是一个独立的 NSH 应用或基准套件，彼此之间无共享代码依赖，统一通过各自的 `nsh.json` + `tsconfig.json` 声明入口与构建配置。

- 轻量示例：`counter/`、`embedded/`、`host-echo/`、`keyboard-capture/`、`tray/`、`tasks/`、`hopper/`、`post-editor/` 等，每个仅含一个 `App.tsx` 根组件，用于演示单一 API（如托盘、键盘捕获、进程回显、任务列表、编辑器）。
- 基准套件 `bench/`：提供 `GridTs`、`RowsTs`、`Inputs`、`RichEditor*`、`PositionalClasses`、`data-table/` 等压测页面，配合 `cargo test --release -p nsh-engine --test engine bench_components` 与 `nsh test ... --trace` 输出 JS/Core 耗时，结果汇总到 `docs/dev/performance.md`。
- 大型演示 `gallery/`：包含 80+ 个 demo（demos/*）、完整的 UI 导航（`nav.ts`、`TitleBar.tsx`、`Bench.tsx`）、声音/字体资源、Python 辅助脚本（`tools/echo.py`、`lucide.py`）以及 120+ 个端到端测试（`tests/*.test.tsx` + `fixtures/`），同时作为 Web/Mobile/Desktop 三端能力对照。
- Rust 对等实现 `gallery-rs/`、`tasks-rs/`、`post-editor/native/`、`rust-exports/native/`：用 Rust 重写 gallery/tasks/post-editor 的 native 层，暴露给 TSX 侧的 App，验证跨语言互操作。
- 嵌入式宿主：`embed-gpui/` 是独立 Cargo workspace（`run/` 为最小启动器，`src/` 实现 trading/watchlist/switch/theme/layers 等 GPUI Kit 宿主逻辑，`app/` 是被嵌入的 NSH 应用），`embed-android/`、`embed-ios/` 提供 Android/iOS 宿主入口；`desktop/` 展示原生桌面宿主挂载。
- 工具集 `nsh-gallery-ui/`：一套可复用的画廊 UI 组件库（`look/` 下的 button/choice/menu/surface/tabs 等），供 gallery 使用，自身也带 `tests/` 子应用。

依赖方向单向：TSX 示例 → NSH 运行时 → 各平台的 native 模块（Rust/Swift/Java），示例之间不互相引用。
