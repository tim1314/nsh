- 运行 Gallery: `cargo run`（仓库根）或 `./target/debug/nsh run examples/gallery`
- 运行 Web 版 Gallery: `nsh run examples/gallery --target web`
- 运行 embed-gpui: `cargo run`（在 examples/embed-gpui 内）或 `cargo run -p example-embed-gpui`（仓库根）
- 基准测试: `cargo test --release -p nsh-engine --test engine bench_components -- --ignored --nocapture`；单页 trace: `nsh test examples/bench/GridTs.tsx --trace`
- data-table 滚动基准: `nsh test examples/bench/data-table/scroll.test.tsx --trace`，外部驱动模式: `EXTERNAL_DRIVER=1 nsh test examples/bench/data-table --target linux --fps -v`
- Gallery 网络 echo 服务: `python3 examples/gallery/tools/echo.py`（监听 9876/9877）
