- 每个示例子目录自包含 `nsh.json` + `tsconfig.json`，以独立 NSH 应用形式被 `nsh run` / `nsh test` 直接消费。
- 示例的 UI 根组件统一命名为 `App.tsx`，并通过 `ui.tsx` 或 `index.tsx` 暴露给 NSH 引擎。
- 需要 native 能力的示例（gallery-rs、tasks-rs、post-editor、rust-exports）将 Rust 源码放在 `native/src/` 下，并在同级 `native/Cargo.toml` 中声明模块。
- 端到端测试采用 `<feature>.test.tsx` 与 `tests/fixtures/<scenario>.tsx` 分离的组织方式，fixture 文件只渲染被测片段。
- Rust 宿主通过 `set_ui_sets` 注册自定义 UI 模块（如 `host/trading`），TSX 侧通过 `nativeModule<{...}>('host/...')` 按名称引入并调用。
